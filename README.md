TO run the project it is very easy 

-> first install docker desktop 
-> now in power shell just go and write docker compose -f "compose.yaml" up  -d (make sure terminal in the same workdir of compose.yaml)
-> this command will start up all the data bases and will be running in background no setup needed from your side 
-> run npm install in root folder as well as frontend folder (both are not integrated to one project yet) 
-> run npm run dev in both folders as well (once in root -> will start backend ) once in frontend -> will start frontend
